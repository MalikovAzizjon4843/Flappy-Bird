# Skrinshotlar / Screenshots

Asosiy `README.md` shu fayl nomlarini kutadi (portrait, masalan 1080×1920 yoki kichraytirilgan 540×960):
The main `README.md` expects these file names (portrait, e.g. 1080×1920 or scaled down to 540×960):

| Fayl / File | Ekran / Screen |
|---|---|
| `menu.png` | Bosh menyu / Main menu |
| `gameplay.png` | O'yin jarayoni (HUD, tangalar) / Gameplay (HUD, coins) |
| `gameover.png` | O'yin tugadi paneli / Game over panel |

Fayllarni qo'shgach, asosiy `README.md` dagi skrinshotlar blokidagi izohni (`<!-- ... -->`) olib tashlang.
After adding the files, remove the comment markers (`<!-- ... -->`) around the screenshots block in the main `README.md`.

Eng oson yo'l — telefonda APK'ni ishga tushirib, oddiy skrinshot olish. Yoki Unity'da Game oynasini 1080×1920 qilib, Play Mode'da ekrandan kesib olish (Windows: Win+Shift+S).
Easiest: run the APK on a phone and take a regular screenshot. Or set the Unity Game view to 1080×1920 and capture it in Play Mode (Windows: Win+Shift+S).
